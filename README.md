# Forja

Web de las apps de Forja (Pulso, Descargador…). Se publica con GitHub Pages.

- `apps.js`: catálogo de apps (textos, capturas, enlace de descarga, versión).
- `img/`: iconos y capturas.
- Los APK se suben como *Releases* del repositorio, no van en el código.
- `publicar.ps1`: sube una versión nueva de una app y actualiza la web.
